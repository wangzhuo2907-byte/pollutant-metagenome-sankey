# 统计与制图口径

## 关联筛选

以每个样本全部细菌记录的丰度总和为分母，含未分类记录。先分别聚合科、属、种，再过滤均值；过滤后不重新归一化。平均相对丰度为各样本比例的等权均值，真实零值参与平均。用户可指定其他分母/丰度定义，但输出必须说清。

使用完整有效样本对，不因细菌未检出而删除零值。Spearman仅说明单调关联；样本很少时近似检验可能对±1相关给出异常零p。置换检验使用`(1+极端次数)/(置换次数+1)`，需满足交换性。重复采样/水层/站位/批次可能混杂，应分层或建模，而不把普通相关当作控制后的结果。

原始p显著不等于多重检验校正后显著。报告BH的检验集合（层级内、全部层级或当前丰度阈值内），不能事后选最有利的q。先按候选与污染物的关联筛选，再分析候选功能，这一同数据筛选后的二次结果仍为探索，不能冒充独立验证。

## 基因联合注释

以细菌基因表分类作为归属依据，Gene_ID=Reference_ID连接。功能源Taxonomy若冲突必须标记，不静默改写分类。去重单位是完整关系，不把一基因多功能丢成第一条。EC_ID若为描述标签，与EC汇总表按描述精确核对；EC编号从源描述另提取，不依据家族猜测具体催化活性。

若源文件的同一基因-家族重复出现大量不同酶描述，核查是否为家族功能列表展开。可以保留“继承的候选EC对应关系”，但不能用描述字符串匹配成功来证明逐基因EC注释可靠。缺少注释不证明功能不存在，宏基因组也不等同表达/酶活。

## 守恒的桑基图权重

对一个分类层级单独处理。候选分类群t的显著污染物集合为P(t)。基因g的去重CAZy家族集合为F(g)。某基因-家族的去重EC编号集合为E(g,f)。重复描述中的同一EC只算一次；该基因-家族完全无编号时用“EC unassigned”占位。

每条完整路径`污染物 → t → f → EC`的权重为：

```text
1 / ( |P(t)| × |F(g)| × |E(g,f)| )
```

每个基因在每张图的总贡献恰好为1；中间节点流入等于流出。同一基因-家族若既有无EC描述又有带EC描述，仅在实际编号集合间分摊，不凭空增加未注释类别。负相关用颜色，流量始终非负。

此权重仅是等分展示约定，不是丰度、真实基因拷贝比例、相关强度、污染物剂量、表达或物质通量。若用户要丰度权重，需要另定义各样本如何汇总并在多个功能标签间分摊，不能混入rho。

按权重排名显示前N个家族、前M个EC，其余归Other；先计算完整路径再合并类别，保证无权重损失。保留EC不完整编号和缺失。每层级分类群全部保留，不取Top30替代候选名单。

合并CAZy/EC节点会失去跨节点的路径身份；相邻连接不证明任意四层组合存在。交互图按单分类群筛选有助核对，具体四元关系以完整路径表为准。科属种独立作图、不能跨层级加总。

## 必做核对

- 同一分析方案中`Level+Taxon_key+Pollutant`唯一；分类ID按字符串连接。
- 基因丰度输出ID唯一，多重功能不重复其丰度。
- 候选/已匹配/未匹配基因数量以及分类冲突数量可追溯。
- 对每层级，完整路径和、分组路径和、首段流量和、末段流量和均等于去重匹配基因数。
- 每个中间节点的流入/流出在浮点容差内一致；无NaN、负流量、无限值。
- 图中标清原始p或q、正负方向、流量单位、Other和预测EC的证据限制。
